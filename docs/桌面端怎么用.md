# 在桌面端 DSH 上用

> 2026-10-30。这份是给电脑上那台 DSH 的，不是手机的。

## 一、最省事：塞进 AGENTS.md

四步，改不了一行代码。

1. **解压**到任意目录，比如 `~/amber-memory`
2. **准备数据**：DSH 导出的书库 zip，或者任意 jsonl
3. **跑三步**：

```bash
cd ~/amber-memory
python3 extract.py --source 你的书库.zip --tag me --out events.jsonl
# 写一份 settings.json，见 README 的「一条命令跑到底」
python3 pick.py
```

4. **接进去**：把生成的 `resident.md` 整段追加到 `~/.dsh/AGENTS.md`

完事。下次开局它就在上下文里，每一轮都在，不用问也在。

## 二、要通道那种

固定 1.6 万 token、两秒开口、不写会话——需要桌面端也有一个 OpenAI 兼容的桥，加一层转发。

我们手机上那套是 `8796 桥 + stateless.js`，**没打进这个包**。要的话单独说，我给。

## 先验一遍

```bash
cd ~/amber-memory
python3 tests/smoke.py
```

跑通了再上真数据。300 条假数据 → 常驻 1,576 字，两秒内出结果。

## 三个注意

- **不用装任何东西**。Python 3.8+，标准库，没有 pip
- **`resident.md` 别进任何仓库**。里面是私事，一句话都不该公开
- **常驻是一次快照**。改了数据不重跑 `pick.py`，它不会自己更新

## 出来什么样

跑完 `resident.md` 长这样：

```
# 常驻

## 对方说过的话
- `01-12 08:22` 记账那笔我忘了记，月底对不上。

## 我说过的话
- `01-05 12:03` 先别急着换，用两天看看。
```

每轮开头把它塞进提示词，就等于带了一本记事本在身上。
